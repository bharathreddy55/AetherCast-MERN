# Project workflow

- After each completed, verified batch of requested changes, update `NEEDED_CAHNGES.MD` with completed items, validation results, and any remaining setup.
- Commit and push that batch to the current GitHub branch through `origin`, unless the user directs otherwise. The user authorized this ongoing workflow on 2026-10-28.
- Keep environment files, credentials, access tokens, and generated dependency/build directories out of commits.
- If a push fails, retain the local commit and report the failure accurately; never claim a push or deployment succeeded without verification.
